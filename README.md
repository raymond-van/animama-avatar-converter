# Animama Avatar Export

Export a VRChat Avatar you own to a VRM file for [Animama](https://github.com/raymond-van/animama),
from inside Unity or from a terminal. Conversion runs on your computer through
[Mochiya Avatar Tools](https://github.com/mochiya-labs/unity-avatar-tools) and
[UniVRM](https://github.com/vrm-c/UniVRM); nothing is uploaded.

Convert only an Avatar whose licence allows conversion for your own use, and do
not share the Avatar or its export unless its licence allows it.

This project is in development; installation instructions follow with the first
release.

## Layout

- `Packages/com.animama.avatar-export/`: the Unity editor package.
