# Animama Avatar Export

Unity editor package that exports a VRChat Avatar to a VRM 1.0 file for Animama.
See the [repository README](https://github.com/raymond-van/animama-avatar-export)
for installation and use.

It requires UniGLTF (`com.vrmc.gltf`) and UniVRM 1.0 (`com.vrmc.vrm`) 0.131.2
and Mochiya Avatar Tools (`org.mochiya.avatar-tools`) 0.1.6 at its tested
commit; its export code compiles only when they are installed. Until then,
**Animama > Check Requirements…** offers to install them.
